## D2(a) Tool set and D2(b) interface experiment

The frozen outpatient-referral agent exposes six tools: get_referral, lookup_patient, check_referral_criteria, as_of, get_clinic_slots and book_slot. Together they separate evidence retrieval from the gated booking action. Patient history and contact details are returned together to avoid an extra lookup; protocol facts are grouped to reduce repeated retrieval. All descriptors remain in the system prompt even when their tools are not called, so descriptor length contributes to recurring input-token cost.

Two executable safeguards constrain incorrect actions. First, slot lookup requires an urgency band and filters slots by specialty, band, date window and positive capacity. The required argument prevents omission, but does not guarantee that the model supplies the correct band. Second, booking validation independently recomputes the referral conditions, duplicate check and eligible slots before accepting a booking. The final booking record must match a successful gated action. The team retained the integrated six-tool contract rather than replacing it with Jason's earlier five-tool prototype.

The controlled experiment changes only the get_clinic_slots descriptor. The v2 text clarifies calling preconditions, argument provenance and empty-list semantics: no available slot requires no_slot_in_window escalation, not a wider window or a different band. The function, return schema, other five descriptors, model, cases and runtime controls remain unchanged. In Fan Yupei's frozen GPT-5.4 paired live runs, code passes increased from 20/58 to 25/58 (+8.62 percentage points), and negative passes from 20/42 to 21/42. Total API tokens increased from 244,149 to 297,983 (+22.05%), while the recorded harness cost increased from US$0.731030 to US$0.881178 (+20.54%). Median turns remained two. Both arms scored 0/3 on the separate evidence-judgement checks. The observed benefit is therefore a performance–cost trade-off, not a cost reduction or a statistically established general improvement.

Jason's individual Gemini 3.7 Flash v2 battery, run through OpenRouter on the same frozen controls, achieved 6/58 code passes (10.34%) and 4/42 negative passes (9.52%). It used 132,992 input and 17,498 output tokens. The exact price-book and provider-reported totals were both US$0.1653615; the harness's sum of rounded trial costs was US$0.165363. Forty-seven trials had strict-JSON parsing failures and two returned empty assistant content, so the low score must be interpreted as performance under this particular harness. The three independent judgement checks were later completed and scored 0/3. This individual-model run is separate from the same-model GPT descriptor comparison.

The local frozen guardrail battery passed 15/15 deterministic tests, and the full suite previously passed 45/45 during environment preparation. These code checks are not live guardrail-pass rates. Exact tool-return tokens per call were not isolated in the saved API usage; the supplied compact-JSON character measurements are explicitly a proxy, not token counts. Wang Chenyu proposed the isolated slot-interface experiment, which the team adapted to its six-tool implementation; live paired evidence remains attributed to Fan Yupei.
