## D6 Cost Model — report-ready text

We converted the five final descriptor-v2 live batteries into a common cost ledger using measured API-reported token counts and the price metadata recorded in each run. The five runs—GPT-5.4, Kimi K2.6, Claude Sonnet 4.6, DeepSeek V4 Pro and Gemini 3.7 Flash—share the same freeze/source commit (`e36bb1b2fcad625ed944e7df863165d95c0ef53f`), prompt v2, descriptor v2, tool contract, 30-case evaluation set and 58-trial policy. A trial that fails the deterministic code check is treated as requiring human fallback. Independent judgement is complete for all five v2 result files: each model passed 0/3 selected prose-evidence cases. We report that result separately and do not mix it into the deterministic code-pass rate used by the D6 fallback calculation.

For the business scenario, we assume US$6 per fallback task, US$5 for manual-only handling, US$150 monthly fixed AI/monitoring cost and 1,000 referrals per month. These values are explicit assumptions rather than observed hospital costs. Under this scenario, the manual-only baseline is US$5,000.00 per month. The base AI-assisted monthly costs are US$3,578.99 for GPT-5.4, US$4,603.96 for Kimi K2.6, US$5,131.03 for Claude Sonnet 4.6, US$5,739.89 for DeepSeek V4 Pro, and US$5,532.16 for Gemini 3.7 Flash. Their deterministic code-pass rates are 43.1%, 25.9%, 17.2%, 6.9%, and 10.3%, respectively.

The ±10 percentage-point sensitivity shows that reliable task completion is the largest cost lever in this scenario. At 1,000 tasks per month and US$6 human fallback cost, a 10 percentage-point improvement in success reduces expected fallback spending by US$600 per month. This is much larger than the observed model API cost per battery, so reducing fallback has a greater economic effect than token-price differences alone. The break-even success rate is about 19% across the five models because model token cost per task is small relative to the assumed human-handling cost.
